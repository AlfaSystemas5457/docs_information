# 📦 Información de empleados y vehiculos

Este módulo permite administrar los documentos de los empleados y vehiculos para da acceso simple a los diferentes documentos del empleado en especifico.

## 🚀 Compatible con versiones de Odoo  
Este módulo es compatible con *Odoo Community 18.0*.

🔗 [Repositorio en GitHub](https://github.com/AlfaSystemas5457/docs_information)

---

## 👷 Acceso facil a los docmuentos

Se agrega un boton para acceder en los botones del modulo *hr* y *fleet*

## 📥 Instalación

Para instalar este módulo, sigue estos pasos:

- Descargar el repositorio:

```bash
git clone https://github.com/AlfaSystemas5457/docs_information
```
- Copiar la carpeta del módulo en la ruta de addons de Odoo.
- Actualizar la lista de módulos en Odoo.
- Instalar el módulo desde la interfaz de Odoo.
